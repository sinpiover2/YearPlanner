# Amplify Math 8 Goal Review

## Purpose

This document preserves the source-grounded, teacher-facing learning goals
reviewed against the local Amplify Math 8 curriculum pages. The goals are
teacher-authored conversions of Amplify's mathematical and language goals,
written in editable student-facing language.

The local Amplify PDFs and screenshots are source evidence only. They remain
untracked and are not included in the repository.

## Review and Write Rules

1. Review every supplied source page, including mathematical goals, language
   goals, assessments, practice days, and synthesis/reflection activities.
2. Preserve distinct goals rather than compressing them into one statement.
3. Treat these as editable teacher-owned goals, not verbatim publisher data.
4. Before a production write, confirm the target Unit's current goal fields
   are in the expected state.
5. Write only `KeyOutcome`, then reload production and verify every goal.
6. Compare all non-goal fields and all out-of-scope Units against the
   pre-write snapshot.
